# Milky Digital Menu (Quick Start)

- Backend: Node/Express + SQLite (JWT auth)
- Frontend: static HTML/JS (menu, auth, dashboard, kitchen)
- AI ChatBot widget included on menu page

## Local
```
cd backend
npm install
cp .env.example .env
npm start
```
Then open `frontend/auth.html` to register, `frontend/index.html?restaurantId=1` to see menu.
